# Copilot作業記録

このプロジェクトの作業依頼や、今後の作業に役立つ決定事項を記録します。

【状態の変更方法】
各メモの先頭にある copilot_context の値を編集して保存してください。
その値は、同じIDの「メモ開始」から「メモ終了」までの内容全体に適用します。

  true    : 次のチャットへの引継ぎに使用する
  false   : 原本に残すが、引継ぎには使用しない
  discard : 専用の削除タスクで削除する予定の項目

新規項目は必ず false で追加します。状態の変更は作業者が行います。
1つのタスクまたは決定を1件とし、各メモを開始・終了コメントで囲んで記録します。
記載例はREADME.mdの「活動ログの記載形式」を参照してください。
