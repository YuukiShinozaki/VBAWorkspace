# Sandbox — VBAコードの試作・検証

AIが作成したVBAコードなどを、本番へ採用する前に試すためのフォルダーです。自動テスト専用の `Tests/` フォルダーは設けず、試作・検証用コードはここで管理します。

## 本番コードとの区別

- `../Source/`：本番ブックからエクスポートしたVBAソース。
- `Sandbox/`：試作コード、検証用コード、必要に応じて用意する試作用Excelブック。
- このフォルダーのコードは、本番へ反映済みとは限りません。検証前のコードを本番ブックへ取り込まないでください。

## 試作・検証を追加するとき

コードは用途が分かる名前で保存し、以下の項目をこのREADMEに追記してください。検証結果は実際に確認した内容のみ記載し、未実施の項目は「未検証」としてください。

- **目的**：何を試すのか。
- **対象ファイル**：試作コードと試作用ブックの名前。
- **関連する本番コード**：対象ブック・モジュール。未定の場合は「未定」。
- **実行入口と手順**：実行するマクロ名と操作手順。
- **前提条件**：必要なシート、データ、参照設定など。
- **期待結果**：どうなれば成功か。
- **検証状況**：未検証／確認済みの範囲、実際の結果。
- **注意事項**：セルの書き換え、ファイル出力などの副作用、本番への反映状況。

## Excelで検証する際の注意

- 本番ブックではなく、コピーした試作用ブックで検証してください。
- `.bas`、`.cls`、`.frm` を保存・編集しただけでは、Excelブック内のコードは変わりません。
- UserFormの `.frm` と関連する `.frx` はセットで管理してください。
- 本番採用時は、対象プロジェクトの手順に従ってブックと `Source/` の両方を更新してください。
- 個人情報、パスワード、APIキーなどをコードや試験データに含めないでください。
