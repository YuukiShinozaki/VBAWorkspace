# UserForm CSV Exporter アドイン

このフォルダーには、UserForm情報をCSVへ出力するスクリプトと、編集したCSVをExcelブックへ反映するスクリプトを置きます。出力タスクは専用アドインを一時的に使い、対象ブックを読み取り専用で開きます。反映タスクはExcelを別プロセスで起動し、選択したCSVに対応する既存UserFormのコントロールを更新します。どちらの処理も作業対象ブックに専用アドインを組み込む必要はありません。

## 初回セットアップ

次の作業では、普段作業しているブックを使わず、アドイン作成専用の空ブックを使ってください。既存の作業ブックへコードを追加することはありません。

1. Excelで新しい空のブックを作成します（作業中のブックは選びません）。
2. 新しい空ブックのVBEを開き、標準モジュール`ExportFormCSV.bas`をインポートします。ファイルは`Projects\Project UserForm\Source\UserForm情報出力サンプル\ExportFormCSV.bas`です。
3. 「デバッグ」>「VBAProjectのコンパイル」を実行し、エラーがないことを確認します。
4. その空ブックを「名前を付けて保存」で「Excelアドイン (*.xlam)」形式にし、このフォルダーへ`UserFormCsvExporter.xlam`という名前で保存します。以降、空ブックは閉じて構いません。
5. Excelの「ファイル」>「オプション」>「トラストセンター」>「トラストセンターの設定」>「マクロの設定」で「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にします。この設定はExcelの設定であり、対象ブックへコードを追加するものではありません。

アドインのマクロ入口は`ExportUserFormCsvFilesForPath`です。`.xlam`は`.gitignore`で除外されるため、利用する端末ごとに上記の手順で用意してください。作成した`.xlam`だけが抽出コードを保持します。

## 実行

1. VS Codeで`Workspace.code-workspace`またはワークスペース直下のフォルダーを開きます。
2. `Ctrl+Shift+P`を押して「タスク: タスクの実行」を選択します。
3. 「Excel: UserForm情報をCSV出力（アドイン）」を選びます。
4. ファイル選択ダイアログで対象の`.xlsm`または`.xlsb`を選択します。
5. 出力完了後、対象ブックと同じフォルダーに作成されたUserFormごとのCSVを確認します。

対象ブックは読み取り専用で処理され、保存されません。VBAプロジェクトが保護されている場合や、ExcelのTrust Center設定が無効の場合は取得できません。パスワード保護されたブックなど、Excelが対話入力を要求するブックは対象外です。

## 編集したCSVをExcelへ反映

1. CSVを編集し、列名・フォーム名・コントロール名・親コントロール名は変更しないでください。`Caption`、`Top`、`Left`、`Width`、`Height`、`TabIndex`の値が反映対象です。数値列を空欄にすると、そのプロパティは変更しません。Captionの空欄はCaptionを空文字にします。
2. 対象ブックをExcelで開いている場合は閉じます。ブックの作業中の未保存変更は保存しておいてください。
3. VS Codeで「タスク: タスクの実行」から「Excel: 編集したUserForm CSVをExcelへ反映」を選び、対象ブックと編集したCSVを指定します。ワークスペース直下の`.vscode/tasks.json`に登録されているタスクです。
4. 表示される変更概要を確認して実行を承認します。反映前に同じフォルダーへタイムスタンプ付きバックアップが作成され、成功時は対象ブックが保存されます。

この反映機能は既存コントロールのプロパティ更新に限定されます。コントロールの追加・削除・種類変更、フォーム全体のプロパティ、フォント・色・画像などCSVに含まれない情報は変更しません。CSV内のコントロールが対象フォームに見つからない場合や同じ親の下で名前が重複して特定できない場合は、更新前に中止します。
